# Flight Operations Manual

## Quick Reference Guide

### Pre-Flight Checklist
- [ ] Weather check (wind <10 m/s, no precipitation)
- [ ] Airspace clearance obtained
- [ ] Battery >90%, cells balanced
- [ ] GPS lock acquired (8+ satellites)
- [ ] All sensors responding
- [ ] Pump test completed
- [ ] Sample bottle empty and seated
- [ ] Ground station connected
- [ ] Failsafes configured
- [ ] Landing area clear

### Mission Phases
1. **Takeoff**: Arm → Ascend to 10m → Climb to cruise (20m)
2. **Navigate**: Fly to target waypoint → Monitor telemetry
3. **Sampling**: Descend to 0.5m → Deploy pipe → Collect sample (5 min)
4. **Return**: Climb to 20m → Navigate home → Land

### Emergency Actions
- **Low Battery (<30%)**: Immediate RTL
- **GPS Loss**: Switch to manual, land ASAP
- **High Wind**: Abort mission, return home
- **Link Loss**: System auto-RTL after 60 seconds

### Normal Mission Timeline
- Total duration: 15-20 minutes
- Battery usage: 70-75%
- Sample collection: 5 minutes
- Data points: 180-240 readings

### Post-Flight
- [ ] Download data logs
- [ ] Clean sensors
- [ ] Empty bottle
- [ ] Charge batteries
- [ ] Log flight
